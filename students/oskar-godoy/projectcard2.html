OWN Carpe Diem RAG Assistant

An assistant that answers from OWN Carpe Diem's own documents — and cites where each answer came from.

What it is

A retrieval-augmented generation (RAG) assistant for OWN Carpe Diem, my wellness venture. Instead of answering from a model's general memory — which can invent details — it retrieves the most relevant passages from the company's own material and answers only from those, with citations back to the source.

What I did

I assembled a document collection for OWN Carpe Diem and split it into passages. Each passage is turned into an embedding with a sentence-transformers model, and the embeddings are stored in a vector index for fast similarity search. When a question comes in, the system embeds it, retrieves the top matching passages, and passes them to the model as grounding, so the answer stays tied to real sources and each claim can be traced back.

What came out

A question-answering assistant that is grounded rather than fluent-but-wrong. Answers come with the passages that support them, which makes the output trustworthy enough to actually use — the whole point of the "fluent is not the same as correct" principle.

Tools and technologies

Python sentence-transformers FAISS (vector search) RAG Anthropic API
