KFE Property Maintenance Bot

A WhatsApp bot that reads dozens of property groups and turns the maintenance messages I'm tagged in into a clean, logged record.

What it is

KFE manages short-term-rental properties, and every building has its own WhatsApp group where issues get reported — a leak, a broken lock, a missing item. The important messages are the ones where I'm tagged, and they were easy to miss across ~40 groups. This bot reads the groups, finds the messages that tag me, and logs each maintenance issue to a Google Sheet automatically.

What I did

I built the bot on Baileys, a WhatsApp library that connects over WebSocket without needing a browser, after an earlier browser-based approach proved unreliable. It listens for new messages, checks whether the owner was tagged, and passes the message to Claude to classify it (what kind of issue, which property, urgency) and write a short summary. The result is appended to a Google Sheet through a service-account connection. It runs on a schedule and keeps a small state file so the same message is never logged twice.

What came out

A working pipeline: WhatsApp groups in, a structured maintenance log out. Instead of scrolling dozens of chats, KFE gets one sheet where every tagged issue is captured, summarized, and dated — ready to assign and track.

Tools and technologies

Node.js Baileys (WhatsApp) Anthropic API (Claude) Google Sheets API node-cron
