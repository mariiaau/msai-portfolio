Current Projects

KFE Property Maintenance Bot

A WhatsApp bot (built on Baileys) that reads ~40 property groups, extracts the maintenance issues where the owner is tagged, and logs each one to Google Sheets using Claude to classify and summarize it. It runs on a schedule and de-duplicates, so nothing gets lost and nothing gets logged twice.

OWN Carpe Diem RAG Assistant

A retrieval-augmented assistant over OWN Carpe Diem's own documents. It embeds the company's material (sentence-transformers), retrieves the most relevant passages with a vector search, and answers with citations — so responses stay grounded in real sources instead of being made up.

Event-Ready Skills Library

A set of single-purpose Claude skills plus one "runner" skill that reads an event email thread and calls the others — generating an on-brand flyer, unique images, and landing-page prompts. It turns repeatable design work into a repeatable, reliable pipeline.
