Event-Ready Skills Library

A set of single-purpose Claude skills — plus one runner that reads an email thread and calls the others to produce a whole event package.

What it is

A library of Claude skills for producing event materials for Atlantis University. Four flyer skills each carry one school's brand (Business, Education, Health, Technology) and interview the user before drawing. An image skill generates unique on-brand images, and a landing-page skill writes ready-to-paste prompts. A "runner" skill ties them together.

What I did

I built each skill to do one job well, then wrote event-ready-generator, a runner that reads an event email thread, extracts the brief once (title, date, speaker, hosting school), and calls the right flyer skill, the image skill, and the landing-page skill in order. Two design rules matter: the flyer's color is read from the hosting school named in the thread — never guessed from the topic — and every image uses a fresh random seed plus a run-ID, so two people can never generate the same one.

What came out

From a single email thread, the chain produces an on-brand flyer, three unique images, and the three prompts that build a matching landing page. Repeatable design work became a repeatable, reliable pipeline instead of a one-off effort each time.
